# Can an exported GenStory.cc project be reimported?

A source-project backup should be reimportable. A runtime or publishing bundle may omit editor-specific structure, so do not treat it as the only backup.

## Important details

- Confirm the actual state of the current project, browser, device, account, or external service.
- Preserve an editable backup before migration, deletion, replacement, or publication.
- Test the workflow with a small non-critical project first.

## Recommended approach

1. Identify which copy is the editable source and where it is stored.
2. Export a recoverable backup before any destructive or cross-device action.
3. Check the permissions, data scope, cost, and retention rules of third-party services.
4. Perform the operation on the smallest useful scope.
5. Reopen, reimport, preview, or run the result to verify it independently.

## Common misconceptions

- Browser-local storage is the same as account-based automatic sync.
- A deployment bundle is always equivalent to an editable source project.
- A success notification proves that restoration or production playback works.
- Every browser, AI model, and hosting environment behaves identically.
