# 如何写适合朗读的绘本文字

控制句长、词汇和重复节奏，让文字补充画面并适合亲子朗读。 本教程按“确定目标—建立结构—完成内容—检查结果—保存下一步”的顺序进行。第一次操作时先做最小版本，确认流程可靠后再扩展篇幅或素材。

## 你将完成什么

完成后，你会得到一份可以继续编辑的结构化成果，而不是一次性生成的零散内容。开始前准备已有设定、参考素材和明确的输出范围；涉及外部 AI、图片或视频服务时，只提交完成当前任务所需的信息。

## 示例 Prompt

替换方括号中的内容。先让 AI 澄清或输出结构，再决定是否生成正文或代码。

```text
为第[页码]页写 3 个朗读版本，每版不超过[字数]字。A 简洁，B 有重复节奏，C 强调角色声音。不得新增画面中没有的重要事件。\n\n[页面计划]
```

生成后至少检查：是否遵守固定设定、是否超出任务范围、是否遗漏关键约束、是否产生无法验证的新事实。发现问题时只重做受影响部分。

## 常见错误

- 一开始就要求生成完整成品，导致结构和约束没有确认。
- 同时修改人物、情节、格式和风格，无法判断问题来源。
- 把 AI 输出直接写回项目，没有保留原稿或变更记录。
- 只检查单页或单场景，不检查与前后内容的连续性。
- 完成后没有导出源项目备份。

## 质量检查表

- [ ] 目标受众、成品形式和范围明确。
- [ ] 固定设定与允许变化的内容分开记录。
- [ ] 每一步都有可以观察的输出。
- [ ] 相关内容之间没有明显冲突或断裂。
- [ ] 外部生成结果已经人工审核。
- [ ] 源项目和关键素材已有独立备份。
