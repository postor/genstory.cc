# GenStory.cc 项目保存在哪里？

项目默认保存在当前设备的浏览器中。项目索引和正文、素材可能分别使用浏览器的 IndexedDB 与 OPFS。创建项目本身不等于上传到 GenStory.cc 服务器。

## 需要注意的情况

- 更换浏览器、设备或浏览器用户配置后，原本地数据不会自动出现。
- 清理站点数据可能同时删除项目索引和素材。
- 重要项目应保留可重新导入的 ZIP，并将备份放到另一个位置。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
