# 清除浏览器数据会删除 GenStory.cc 项目吗？

可能会。清除 genstory.cc 的站点数据、IndexedDB 或 OPFS 可能删除本地项目。无痕窗口关闭后也不适合作为长期保存环境。

## 需要注意的情况

- 操作前先导出项目 ZIP。
- 确认备份文件大小合理，并执行一次测试导入。
- 只清理缓存与清理完整站点数据的影响不同，操作前应核对浏览器提示。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
