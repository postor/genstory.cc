# GenStory.cc 可以使用自定义 AI API 吗？

如果当前设置支持 OpenAI 兼容接口，可以配置自己的服务。使用前必须确认浏览器端请求、CORS、密钥暴露、费用和数据处理规则。

## 需要注意的情况

- 不要把长期高权限密钥放在公开或共享设备。
- 为前端使用的密钥设置额度与权限限制。
- 接口兼容不代表所有模型能力和参数完全相同。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
