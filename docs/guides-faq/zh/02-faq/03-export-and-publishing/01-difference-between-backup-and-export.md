# 项目备份 ZIP 和发布导出有什么区别？

项目备份用于重新导入 GenStory.cc 并继续编辑；发布导出用于运行或部署成品。发布包可能经过转换，不能替代源项目。

## 需要注意的情况

- 每次重要发布同时保留源项目 ZIP。
- 发布包需单独测试入口和资源路径。
- 恢复编辑时优先使用明确标记的备份包。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
