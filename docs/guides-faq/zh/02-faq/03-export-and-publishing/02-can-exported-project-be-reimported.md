# 导出的 GenStory.cc 项目可以重新导入吗？

用于备份的源项目 ZIP 应当可以重新导入；用于发布的运行包不一定保留编辑器需要的结构，因此不能默认重新导入。

## 需要注意的情况

- 导出时区分 backup 与 publish 文件名。
- 发布前执行一次备份恢复测试。
- 不要只保存部署后的压缩包。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
