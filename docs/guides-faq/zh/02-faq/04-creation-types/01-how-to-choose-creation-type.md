# 图书、绘本、漫画、视觉小说、互动视频和游戏应该怎么选？

按最终交付形态选择：长文本用图书；逐页图文用绘本；格子叙事用漫画；对白、立绘和选择用视觉小说；视频节点用互动视频；需要玩家持续操作则用游戏。

## 需要注意的情况

- 不要只按素材类型选择。
- 同一故事可以在不同项目中复用人物和设定。
- 先选择最接近最终成品的结构。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
