# 创建后可以直接把一种项目变成另一种类型吗？

不建议假定可以无损转换。不同类型有不同结构和运行目标；更稳妥的是创建新类型项目，再迁移可复用的人物、世界观、提纲和素材。

## 需要注意的情况

- 先列出可复用与必须重做的内容。
- 保留原项目作为来源与备份。
- 迁移后按新类型重新设计节奏。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
