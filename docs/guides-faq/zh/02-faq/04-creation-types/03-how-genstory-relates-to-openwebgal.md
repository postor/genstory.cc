# GenStory.cc 与 WebGAL / OpenWebGal 是什么关系？

GenStory.cc 负责浏览器内的项目编辑、脚本和素材组织及导出准备；OpenWebGal 是视觉小说可运行的目标格式和运行环境。

## 需要注意的情况

- 编辑项目和运行项目是两个阶段。
- 导出前应测试分支和素材路径。
- 同时保留源项目备份和运行包。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
