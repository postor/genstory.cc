# GenStory.cc 能直接生成完整漫画页面吗？

接入图片生成能力后可以生成漫画图像，但稳定流程仍是先完成角色和场景参考、页面分镜与对白空间，再逐页生成和人工检查。

## 需要注意的情况

- 一次生成整页的可控性通常低于逐格处理。
- 对白建议后期排版以保证可读性。
- 角色一致性需要参考和逐格审核。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
