# AI 可以一次生成完整绘本吗？

AI 可以帮助生成故事、逐页文字和插图，但一次性生成整本通常难以保证年龄适配、页面节奏、角色外观和文字准确。建议分阶段完成并逐页审核。

## 需要注意的情况

- 先确认故事和页数，再生成逐页计划。
- 先建立角色参考，再生成插图。
- 只重做有问题的页面，避免全书随机变化。

## 建议做法

1. 先确认当前项目、设备或外部服务的真实状态。
2. 在会覆盖、迁移、清理或发布之前保留一份可恢复备份。
3. 用最小项目测试流程，不要第一次就操作唯一正式版本。
4. 对 AI 或第三方服务，检查发送范围、权限、费用和数据规则。
5. 操作完成后重新打开、导入或预览，确认结果符合预期。

## 常见误区

- 把浏览器本地保存理解成账号自动同步。
- 把发布包当成可继续编辑的源项目。
- 看到操作成功提示就跳过恢复或运行测试。
- 假设所有浏览器、模型或部署环境的行为完全相同。
