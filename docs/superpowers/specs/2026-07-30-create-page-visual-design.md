# 创建页视觉优化设计

## 目标

参考 `docs/design/create/pc.png` 与 `docs/design/create/h5.png`，优化 `/projects/new` 创建页的主体显示效果，同时保持现有产品已经风格化的顶部栏和首页卡片视觉不变。

## 保持不变

- 不修改 `components/site-header.tsx` 与全局顶部导航的布局、颜色和交互。
- 不修改首页 `CreationTypeCard` 的结构和视觉实现。
- 不改变创建项目的业务流程：类型选择、名称填写、文件系统初始化、项目保存、跳转编辑器和错误弹窗都继续使用现有逻辑。
- 不引入新的资产路径；类型图片继续使用 `public/home/type-icons` 下已有图片。

## 页面结构

### 桌面端

- 创建页使用与首页一致的淡紫背景、深紫文字、白色半透明卡片、淡紫边框和柔和阴影。
- 主内容在 `xl` 断点形成约 `minmax(0, 1fr) 320px` 的双栏布局：
  - 左栏是创建表单。
  - 右栏是 CC 助手说明卡，使用已有 `public/home/assistant-bust.png`，不影响表单交互。
- 标题区保留“新建作品”和副标题，取消按钮继续链接到 `/projects`，只调整尺寸与间距以匹配创建页背景。
- 类型区域在桌面端使用可复用卡片视觉，展示类型图片、标题、短描述和选中状态。
- 作品名称输入使用有图标的高可视输入容器。
- 主按钮使用首页主按钮的紫色和阴影风格，继续触发真实创建逻辑；辅助“创建后稍后编辑”入口保持为次要操作。

### 移动端

- 页面改为单栏，右侧助手卡移动到表单末尾。
- 类型选择改为：
  - 当前选中类型展示较大的图片、标题和描述。
  - 其他类型展示为紧凑的横向可点击行，保留图片、标题和加号图标。
- 类型列表仍然是同一组按钮和 `aria-pressed` 状态，不改变可访问性语义。
- 主按钮全宽，取消按钮保持顶部右侧。
- 增加底部安全间距，避免移动端固定导航或浏览器 UI 遮挡主按钮。

## 视觉令牌

- 页面背景：`#fbfaff` 到白色的淡紫纵向渐变，并保留轻量星光/网格装饰。
- 文本：标题使用现有深紫 `#121331`，说明文字使用首页的 `#6b6a89` 系列。
- 强调色：复用首页 `#8754ff` / `#7642ef`，避免创建新的紫色体系。
- 卡片：复用首页 `border-[#e9e5fb]`、`bg-white/90`、`shadow-[0_10px_24px_rgba(92,75,160,0.06)]` 等既有组合。
- 选中状态：紫色边框、轻微紫色背景、环形勾选图标和更明显阴影。
- 圆角与按钮：沿用 shadcn `Card` / `Button` 的现有圆角语义，不使用 inline style。

## 交互与状态

- 选择类型立即更新选中卡片、默认名称 placeholder 和右侧助手文案。
- 未选择类型的保护逻辑保持现状。
- 提交中继续显示 `Loader2`，并禁用主按钮。
- 错误继续通过 `InteractionModal` 展示。
- 卡片和按钮提供 hover、focus-visible、disabled 状态。

## 验证标准

- 顶部栏在修改前后保持一致。
- 桌面端创建页接近 `pc.png` 的双栏构图和视觉密度。
- 移动端创建页接近 `h5.png` 的单栏、选中大卡和未选中紧凑行。
- 所有类型图片加载成功，创建流程仍能进入编辑器。
- `npm run lint` 与相关创建页测试通过。
- 在桌面和移动视口检查无横向溢出、文字裁切和按钮遮挡。
