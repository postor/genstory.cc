# 创建页视觉优化设计

## 目标

参考 `docs/design/create/pc.png` 与 `docs/design/create/h5.png`，优化 `/projects/new` 创建页主体显示效果，同时保持现有产品已经风格化的顶部栏和首页卡片视觉不变。

## 保持不变

- 不修改 `components/site-header.tsx` 与全局顶部导航的布局、颜色和交互。
- 不修改首页 `CreationTypeCard` 的结构和视觉实现。
- 不改变创建项目的核心流程：选择类型、默认命名、可编辑名称、文件系统初始化、项目保存、跳转编辑器和错误弹窗。
- 类型图片继续使用 `public/home/type-icons` 下已有图片，CC 助手继续使用 `public/home/fg.png`。

## 页面结构

### 桌面端

- 创建页使用与首页一致的淡紫背景、深紫文字、白色半透明卡片、淡紫边框和柔和阴影。
- 主内容在 `xl` 断点形成约 `minmax(0, 1fr) 320px` 的双栏布局：
  - 左栏是类型卡片区域。
  - 右栏是 CC 助手说明卡，不影响表单交互。
- 标题区保留“新建作品”和副标题，取消按钮继续链接到 `/projects`。
- 类型区域只展示卡片，不展示页面底部作品名称输入和页面底部创建按钮。
- 每张类型卡片标题行右侧显示 `Go` 操作；点击卡片任意区域或 `Go` 都打开同一个创建弹窗。
- 类型卡片不再有选中态、勾选图标、`aria-pressed` 或当前选择说明。

### 移动端

- 移动端同样直接展示卡片网格/单列卡片，不再使用选中大卡与未选中紧凑行的手风琴效果。
- 每张卡片保留图片、标题、描述和 `Go` 操作。
- 点击卡片或 `Go` 打开创建弹窗。

### 创建弹窗

- 使用 shadcn/base-ui Dialog 组件，不手写弹窗。
- 弹窗根据点击的类型展示类型信息和对应助手提示。
- 输入框使用默认命名作为真实 value，而不是 placeholder，并在弹窗打开后自动 focus。
- 弹窗底部提供“创建并编辑”和“取消”按钮；提交中显示 loader 并禁用操作。
- 用户清空输入后创建时，仍使用当前类型的默认命名兜底。

## 视觉令牌

- 页面背景：`#fbfaff` 到白色的淡紫纵向渐变，并保留轻量星光/背景图氛围。
- 文本：标题使用现有深紫 `#121331`，说明文字使用首页的 `#6b6a89` 系列。
- 强调色：复用首页 `#8754ff` / `#7642ef`。
- 卡片：复用首页 `border-[#e9e5fb]`、`bg-white/90`、`shadow-[0_10px_24px_rgba(92,75,160,0.06)]` 等组合。
- `Go` 操作使用小型紫色按钮视觉，但作为卡片整体点击目标的一部分，避免嵌套 button。
- 圆角与按钮：沿用 shadcn `Card` / `Button` / `Dialog` / `Input`，不使用 inline style。

## 验证标准

- 顶部栏在修改前后保持一致。
- 页面主体没有选中态、勾选图标、`aria-pressed`、底部名称输入区或底部页面创建按钮。
- 桌面端类型卡片为网格，右侧助手卡保持可见。
- 移动端直接展示卡片，不再手风琴折叠。
- 卡片点击和 `Go` 点击都会打开命名弹窗。
- 弹窗输入框默认填入命名并自动 focus，底部有创建和取消。
- 所有类型图片加载成功，创建流程仍能进入编辑器。
- 相关创建页测试、定向 lint、TypeScript 和构建通过，浏览器检查无横向溢出、文字裁切和按钮遮挡。
