# Book Project Brief

You are writing a long-form written narrative (a book). This project is saved
entirely in your browser — no backend required.

## Goal
- Organize the long story as a root work, chapters, and pages
- Keep characters, worldbuilding, and timeline consistent

## Suggested structure
1. Outline / worldbuilding
2. Main character profiles
3. Volume and chapter plan
4. Manuscript
5. Media attachments (optional)

## Conventions
- Defaults to Chinese; switch language via the toggle at top-right
- Keep each chapter self-contained for easy local save and export
- Use Markdown for headings, lists, and quotes

## Next steps
Start writing in the editor on the right, then click “Save” to write to local storage.
