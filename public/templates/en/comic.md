# Comic Project Brief

You are creating a serial visual work (a comic). This project is saved in your
browser — no backend required.

## Goal
- Organize the story around panels, pages, characters, and visual assets
- Keep the art style and character visuals consistent

## Suggested structure
1. Worldbuilding and art direction
2. Character profiles (with appearance notes)
3. Storyboard script (per-page shots)
4. Page and dialogue layout
5. Visual asset list

## Conventions
- Use Markdown to record storyboards and dialogue
- Describe character appearance concretely for later drawing
- Switch between Chinese and English via the top-right toggle

## Next steps
Write the storyboard in the editor on the right, then click “Save” to local storage.
