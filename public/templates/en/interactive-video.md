# Interactive Video Project Brief

You are creating a playable, interactive narrative (an interactive video). This
project is saved in your browser — no backend required.

## Goal
- Compose the interactive story from video clips, audio, and choice points
- Let viewer choices affect how the story unfolds

## Suggested structure
1. Worldbuilding and AV direction
2. Character and scene list
3. Clip script and timeline
4. Choice points and branch logic
5. Ending design

## Conventions
- Use Markdown to record clips and choice points
- Annotate which clip each choice point leads to
- Switch between Chinese and English via the top-right toggle

## Next steps
Write the script in the editor on the right, then click “Save” to local storage.
