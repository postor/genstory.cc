# 小红帽（视觉小说模板示例）

本模板演示如何使用 GenStory.cc 的视觉小说约定（参见仓库 `AGENTS.md`）编写一部可玩的视觉小说，
并构建为 OpenWebGal 项目。故事为经典《小红帽》的简化改编。

## 设定（Canon）
- 小红帽：戴着红帽的小女孩。
- 大灰狼：森林中的反派。
- 外婆：生病在家的小红帽的外婆。
- 猎人：拯救者。

## 时间线（Timeline）
1. 小红帽出门去看外婆。
2. 森林中遇到大灰狼（分支：听狼的话去采花 / 直接去外婆家）。
3. 大灰狼先到外婆家，吞下外婆并伪装成她。
4. 小红帽到达，猎人出现并解救大家。
